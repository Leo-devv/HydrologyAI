# Masuria Lake District Environmental Analysis Platform

## Overview

An advanced web application for monitoring and predicting environmental changes in the Masuria Lake District using AI-powered analysis and satellite imagery. The platform provides detailed insights into water body changes, vegetation patterns, and climate impacts from 2000 to 2050.

## Key Features

### 1. Interactive Satellite Comparison

- Side-by-side comparison of historical (2000) and current satellite imagery
- Slider view for direct before/after comparison
- Overlay mode with opacity control
- High-resolution satellite imagery integration

### 2. AI-Powered Predictions

- Advanced machine learning model for environmental forecasting
- Predictions available from 2025 to 2050
- Key metrics tracking:
  - Water Level Changes
  - Temperature Trends
  - Precipitation Patterns
  - Vegetation Index (NDVI)
- Confidence scoring for predictions

### 3. Environmental Impact Analysis

- Comprehensive assessment of:
  - Ecosystem Changes
  - Tourism Impact
  - Water Resources
  - Wildlife Effects
- Real-time data visualization
- Detailed trend analysis

### 4. Professional Reporting

- Automated PDF report generation
- Detailed environmental analysis
- Historical comparisons
- Future predictions
- Mitigation recommendations
- Professional formatting and layout

### 5. Interactive Dashboard

- Real-time data visualization
- Customizable date ranges
- Multiple view options
- Responsive design

## Technology Stack

- React.js
- TypeScript
- Tailwind CSS
- Shadcn/ui Components
- jsPDF for report generation
- Modern ES6+ JavaScript

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/hydrology-frontend.git
cd hydrology-frontend
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Usage Guide

### Satellite Comparison

1. Navigate to the main dashboard
2. Use the slider to compare historical and current images
3. Switch between different comparison modes using the toggle buttons
4. Adjust opacity in overlay mode for detailed comparison

### Generating Predictions

1. Select a target year (2025-2050)
2. Click "Predict" to generate analysis
3. View detailed metrics and confidence scores
4. Download comprehensive PDF report

### Environmental Impact Assessment

1. Navigate to the Impact Analysis section
2. Review different impact categories
3. Explore detailed findings
4. Access mitigation recommendations
