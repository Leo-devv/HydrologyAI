# HydroScan: AI-Powered Hydrological Change Detection

HydroScan is a web application that uses AI to detect and analyze hydrological changes in satellite imagery. The system can identify water bodies, measure their area, and track changes over time.

## Features

- Upload satellite imagery for analysis
- AI-powered detection of water bodies
- Measurement of water surface area
- Change detection over time
- Professional, user-friendly interface

## Architecture

The application consists of two main components:

1. **Frontend**: React-based interface for image upload and result display
2. **Backend**: FastAPI service that handles image processing and AI analysis

## Prerequisites

- Node.js (v14 or higher)
- Python (v3.8 or higher)
- pip (Python package manager)

## Setup and Installation

### Backend Setup

1. Navigate to the backend directory:

   ```
   cd backend
   ```

2. Create a virtual environment:

   ```
   python -m venv venv
   ```

3. Activate the virtual environment:

   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`

4. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

5. Start the backend server:
   ```
   uvicorn main:app --reload
   ```
   The backend will be available at http://localhost:8000

### Frontend Setup

1. Navigate to the frontend directory:

   ```
   cd ..  # If you're in the backend directory
   ```

2. Install dependencies:

   ```
   npm install
   ```

3. Start the development server:
   ```
   npm start
   ```
   The frontend will be available at http://localhost:3000

## Usage

1. Open the application in your web browser at http://localhost:3000
2. Upload a satellite image using the drag-and-drop interface or file browser
3. The system will analyze the image and display results, including:
   - Water body detection
   - Surface area measurement
   - Change detection results (if applicable)

## Supported Image Formats

- JPEG (.jpg, .jpeg)
- PNG (.png)
- TIFF (.tif, .tiff)

## Browser Compatibility

- Chrome (recommended)
- Firefox
- Safari
- Edge

## Troubleshooting

- **Image upload fails**: Ensure your image is less than 10MB and in a supported format
- **Backend connection error**: Make sure the backend server is running
- **Detection fails**: Use clear satellite imagery of water bodies for best results
